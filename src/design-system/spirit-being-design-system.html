Usage guidelines

  1. New UI — use sb-* classes first.
  2. Colors — prefer var(--sb-color-*) over hardcoded hex.
  3. Dark sections — wrap in .sb-surface-dark for #0a0a0a bands.
  4. TypeScript — import from src/design-system/tokens.ts.
  5. Legacy — aliases like --paper, --electric still work.

Dark surface

Use .sb-surface-dark for Instagram feed, hero overlays, and editorial dark bands.
